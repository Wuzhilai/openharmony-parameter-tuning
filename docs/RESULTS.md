## 方法与目标

- default：调度 (20000,50)，内存 (8,0)。
- heuristic：人工制定的参照，调度 (5000,50)，内存 (16,32)，不称为专家最优。
- random/bo：分别从训练搜索胜者中，经独立验证选出的全局固定参数；不是每次测试重新搜索。
- context：默认参数独立 pilot 后由浅树推荐，越域回退。

调度 `J = mean_turn + 0.5*p95_response`，单位是虚拟客体定时器周期。S 上下文是任务数、循环工作量档位。测试中 P95 实际为批内最大首次响应。

内存 `J = (elapsed-probe_cycles)/ops + 0.0002*live_used + 5000*fails/allocs`，是人工加权分数，不是时间。M 上下文是操作数、尺寸模式。模式 0/1/2/3 的最大请求分别为 48/512/2048/8192 字节。池大小 128 KiB，槽位 256。

## 字段定义

| 字段 | 含义与限制 |
|---|---|
| kind / stage | S 调度或 M 内存；训练、验证、预采样或测试阶段 |
| context / parameters | 工作负载上下文二元组 / 实际参数二元组 |
| seed / rep / method | 随机种子、重复编号、参照方法；同种子不保证高压力内存同请求轨迹 |
| score | 按 kind 对应公式计算的目标，越小越好 |
| mean_turn / p95_response | 从共同起点到完成的均值 / 首次运行等待的近秩 P95 |
| elapsed | 被测内层的客体计时，不包含全部外层费用 |
| host_seconds | 主机串口等待与执行墙钟，不能替代客体执行时间 |
| switches | 有探针时记录的调度切换次数 |
| probe_cycles | 直接计时的采样开销，未包含全部间接扰动 |
| allocs / requested / fails | 分配尝试数 / 累计请求字节 / 分配失败数 |
| live_used / free / maxfree | 结束状态的占用 / 总空闲 / 最大空闲块字节 |
| sampled_peak | 稀疏采样最大占用，不是精确峰值 |
| corrupt / integrity / restored_used / deinit | 首尾字节哨兵错误数 / 池检查返回 / 清理后占用 / 注销返回 |
| features | 独立 pilot 得到的输入特征向量 |
| ood | pilot 是否被域规则拒绝；只有 context 方法据此回退 |

## 数据数量

3144 = 60 条训练 pilot + 1920 条候选训练 + 222 条验证默认对照 + 222 条候选验证 + 120 条测试 pilot + 600 条正式测试。探针实验、60 组部署闭环和120条消融另存，不混入主表。

同一个上下文的 5 种方法共享正式测试 seed；配对统计使用 seed/rep，不能把 5 次方法运行当 5 个独立随机样本。模型只训练一次，不把测试区间当作重训练不确定性的区间。
